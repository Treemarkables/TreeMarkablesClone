# Vibe Quote & Proposal Builder

## Objective
Build a React component in Replit for generating customizable quotes, proposals, and emails. Key features:
- Customizable templates with placeholders for customer name, date, bank details, etc.
- Easy form-based template editing
- Ability to save and load templates
- Integration with Vibe job data
- Clean, intuitive UI using shadcn/ui and Tailwind CSS
- Well-structured, type-safe code with React, TypeScript, Vite 
- Server-side PDF generation for download/email (stretch goal)

## Technical Stack
- Frontend: 
  - React 
  - TypeScript
  - Vite
  - Tailwind CSS
  - shadcn/ui component library
  - HTML/CSS for template editing
- Backend:
  - Node.js
  - Express  
  - PostgreSQL (via Drizzle ORM)

## Component Breakdown

### TemplateEditor
- Renders the currently selected template for editing
- Uses contentEditable or a rich text editor to allow editing template text/HTML
- Highlights template variables for easy identification
- Saves updated template content to the backend on change
- Allows adding new template variables via UI

### TemplateList
- Displays list of saved templates 
- Allows creating a new template
- Click a template to load it into the TemplateEditor
- Enable deleting templates

### TemplateVariableForm
- Form for entering values for the template variables
- Populated from Vibe job data where possible (customer name, job details, etc.)
- Freeform entry for other fields
- Updates TemplatePreview on change

### TemplatePreview
- Renders the final quote/proposal/email
- Template content + entered variable values
- Updates in real-time as TemplateVariableForm changes
- Provide "Copy HTML" and "Download PDF" options

### APIClient
- Fetches list of templates from backend
- Sends updated templates to be saved
- Retrieves job details from Vibe API to populate TemplateVariableForm
- Sends final generated content to backend for PDF rendering

## Backend API
POST /templates
- Create new template
GET /templates 
- List all templates
PUT /templates/:id
- Update template content
DELETE /templates/:id
- Delete a template
POST /pdf
- Generate PDF from HTML content
GET /jobs/:id
- Retrieve job details from Vibe to populate form

## Development Steps
1. Set up React+TS+Vite project
2. Create UI scaffold with shadcn/ui 
3. Implement TemplateList and TemplateEditor components
4. Build Express API for template CRUD
5. Integrate TemplateList with backend API
6. Add TemplateVariableForm and hook up to Vibe API for job details
7. Develop TemplatePreview to render template + variables
8. Implement live updating of TemplatePreview
9. Enable "Copy HTML" on preview
10. Set up backend PDF generation and allow downloading preview as PDF
11. Polish UI and gather user feedback
12. Deploy and integrate into Vibe!
